# VDJdive ECLIPSE Methods Manuscript
Code used to make figures and for analysis in the VDJdive/ECLIPSE methods manuscript

## Running the code:
Analysis is split by figure, except for figure 3 which is combined with extended data figure 1.
All helper functions are either available on the "VDJdive_ECLIPSE_paperFunctions.R" file or in the ECLIPSE.R file of the ECLIPSE package repo.
